Install once

Add Hover Card Preview to your website

Place one script tag immediately before the closing </body> tag. No per-link markup or framework dependency is required.

Production snippet

<script src="https://linkid.io/embed/linkid-hover.js"></script>

What happens next

  1. External HTTP(S) links are discovered automatically.
  2. Matching LinkIDs receive an interactive preview.
  3. Preview details load only when the card opens.
  4. Links added later are detected automatically.
  5. Destinations are never rewritten by this widget.
